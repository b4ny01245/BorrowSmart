# 📦 BorrowSmart

A QR code-based asset management system developed during my internship to streamline the borrowing and return of company assets such as office equipment, tools, and keys.

## Overview

BorrowSmart digitizes the asset lending process by replacing manual record-keeping with a secure QR-based workflow. The system enables employees to borrow and return company assets efficiently while maintaining accurate transaction records and accountability.

## Features

* 📱 QR Code-based Asset Identification
* 📦 Asset Borrowing and Return Management
* 👤 Borrower Tracking
* 👤 Company Authentication
* 📸 Photo-Proof Submission for Returns
* ✅ Return Verification
* 📋 Asset Status Monitoring
* 🔐 Secure User Authentication
* ☁️ Cloud-based Data Storage
* 📊 Real-time Transaction Records
